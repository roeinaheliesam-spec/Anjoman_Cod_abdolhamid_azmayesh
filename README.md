# انجمن کدنویسی دبیرستان عبدالحمید آزمایش بندر خمیر

وب‌سایت آموزش مقدماتی پایتون شامل شش جلسه، مثال‌ها، خروجی کدها و چالش‌های تمرینی. صفحه اصلی سایت در فایل `index.html` قرار دارد.

## لینک‌ها
- مخزن گیت‌هاب: https://github.com/roeinaheliesam-spec/Anjoman_Cod_abdolhamid_azmayesh
- سایت عمومی: پس از فعال‌سازی GitHub Pages در بخش Settings → Pages در دسترس خواهد بود.
- انجمن ایتا: https://eitaa.com/codnevisi_azm
- ارسال پاسخ تمرین‌ها و چالش‌ها: https://digiform.ir/wcbc45de9f

## انتشار سایت
در مخزن وارد Settings → Pages شوید. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید، شاخه `main` و پوشه `/(root)` را انتخاب کنید و Save بزنید. چون فایل اصلی با نام `index.html` در ریشه مخزن قرار دارد، به‌عنوان صفحه اصلی منتشر می‌شود.
